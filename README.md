# Reptilia Studio – mobile app privacy policies

Public privacy policy and terms pages for Reptilia Studio apps, served with GitHub Pages:

- Dokunesia – Privacy: https://dxsantoso.github.io/mobile-apps-privacy-policy/dokunesia/privacy/
- Dokunesia – Terms: https://dxsantoso.github.io/mobile-apps-privacy-policy/dokunesia/terms/

The Dokunesia pages are generated from the app's own legal text (`src/legal/content.ts` in the
private `dokunesia` repo) with `npm run build:legal-site`. Don't edit them by hand; change the app
text, bump `TERMS_VERSION`, regenerate and copy the `dokunesia/` folder here.
