1. Tentang Dokunesia

Dokunesia (“Aplikasi”) disediakan oleh Reptilia Studio (“kami”) untuk menambahkan watermark pada foto dokumen seperti KTP, KK, NPWP, SIM, atau paspor. Dengan memakai Aplikasi, kamu menyetujui Syarat & Ketentuan ini dan Kebijakan Privasi.

2. Data kamu tetap di HP-mu

  • Foto dokumen, teks watermark, dan hasilnya diproses langsung di perangkatmu.
  • Kami tidak mengunggah, menyimpan, atau mengirim dokumenmu ke server mana pun. Dokunesia tidak punya server dan tidak memakai akun.
  • File sementara dihapus otomatis, dan metadata foto (mis. lokasi GPS) dibuang dari hasil.
  • Hasil hanya disimpan ke galeri atau dibagikan jika kamu sendiri memilihnya. Setelah dibagikan, dokumen dikelola oleh aplikasi atau pihak penerima.
  • Rinciannya ada di Kebijakan Privasi, yang disusun mengacu pada UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi.

3. Iklan

Aplikasi ini gratis karena menampilkan iklan dari Google AdMob. Untuk itu, SDK Google dapat memproses ID iklan perangkat, alamat IP, dan info perangkat umum, termasuk di luar Indonesia. SDK iklan tidak pernah mendapat akses ke dokumenmu. Kamu bisa mengatur persetujuan iklan di Aplikasi dan di pengaturan perangkat.

4. Penggunaan yang benar

Kamu setuju untuk:

  • hanya memproses dokumen milikmu sendiri atau dokumen yang kamu berhak gunakan;
  • tidak memakai Aplikasi untuk memalsukan, mengubah isi, atau menyalahgunakan dokumen orang lain, atau untuk perbuatan yang melanggar hukum.

Watermark membantu membatasi penyalahgunaan salinan dokumen, tetapi tidak menjamin dokumen tidak akan disalahgunakan, dan bukan pengganti legalisir atau verifikasi resmi.

5. Hak kamu sebagai konsumen

Ketentuan ini tidak mengurangi hak-hakmu menurut UU No. 8 Tahun 1999 tentang Perlindungan Konsumen dan UU Pelindungan Data Pribadi. Bagian yang bertentangan dengan peraturan tersebut tidak berlaku, dan bagian lainnya tetap berlaku.
